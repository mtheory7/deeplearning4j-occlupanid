This is a working Java based neural network designed to classify images of occlupanid to their genus/species. It uses SqueezeNet and Deeplearning4j along with 300 images (150 images for 2 classes) to train.

Currently, the model is very accurate - validation during training reports 97.62% accuracy - running the final model on all 300 images only misclassifies 1 image, 99.67% accuracy

Genus/Species currently supported, more to come(2): Admordorsum floridensis, Palpatophora utiliformis
